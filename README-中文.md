# 💰 记账本 PWA —— 新手部署教程

纯静态网页，无需安装任何软件，上传到 GitHub 即可使用。没有打包步骤，所有文件都在仓库根目录，用相对路径。

## 最新更新：设置折叠、记住设定、报表筛选成员

- **设置页改成下拉式**：每一项（个人资料、外观、账本设置、支出分类、收入分类、固定账单、银行卡、成员、账号）只显示标题和一行简介，点一下展开，再点收起。哪几项是展开的会记住。
- **记住最后的设定**：选了夜林、换了头像或昵称，下次打开还是一样，换手机登录也会跟过去。在另一台手机改过的话，以最新改的为准。报表里选的图表方式（分类、银行卡、成员）也会记住。
  - 之前会变回去，是因为 Firebase 上还是旧规则，不认识「夜林」，整笔资料（连头像）都没存上。现在即使没发布新规则也能保存。
- **报表可以筛选成员**：报表顶部可以选「全部成员」或只看某一个人，支出、收入、图表、分类变化、6 个月趋势都会跟着变。只看某个人时不显示预算（预算是大家共用的）。

不需要改 Firestore 规则。手机缓存版本现在是 `sw.js` 里的 `expense-v9`。

## 上一次更新：出游分账、夜林主题、设置移到右上角

- **出游分账**：底部最右边的「出游」。和朋友去旅行时开一个旅行，填好一起去的人（只要名字，不用注册），选货币。
  - 「记消费」：写买了什么、谁付的，选要 AA 分给哪几个人（默认全员），会显示每人多少。付款人也可以选「公款付」。
  - 「存公款」：记下谁往公款里放了多少钱。
  - 「结算」会自动算出最少的几笔转账，让大家两清；公款用剩的钱会算成退回给大家。转完账点「已付」就会记下来。
  - 「每个人」显示每人应摊多少、已经付出多少、差额是多少。点明细里的任何一笔可以修改或删除。
  - 右上方「编辑」可以改名字、图标、货币和人员，也可以标记旅行已结束或删除旅行。已经有记录的人不能删除。
- **只剩两个主题**：「森林」和新的暗色「夜林」（有星星和月亮）。以前选清新或暖色的会自动变成森林，选深色的会变成夜林。
- **「存款」改名为「基金」**。
- **设置**移到了右上角 ⚙️，底部标签栏现在是：首页、基金、＋、报表、出游。
- **点开中间的 ＋ 时**，其他标签会变灰、点不动，要先点 ✕ 关掉。

**规则小改了一处**（允许保存「夜林」主题）。请把 `firestore.rules` 再发布一次；不发布也能正常用，只是换手机登录时夜林主题跟不过去。出游分账不需要改规则。



## 更早的更新：新首页、底部 ＋ 按钮、计算器、森林主题

- **首页更简洁**：只显示本月总消费、筛选和明细。图表、预算都搬到了「报表」。
- **底部中间的 ＋**：点一下会展开两个按钮——「消费」（记支出或收入）和「存款」（Tabung 存入或新建目标），再点 ✕ 收起。点底部标签时会有一束光照亮当前的按钮。
- **记账表格**：自带计算器，可以直接算 `15.00 + 2.50`、`120.00 × 3`。照旧只要按数字，小数点自动出现；按「00」可以快速输入整数。整个表格（包括保存按钮）一屏放得下，不用上下拉。右上角 🗑 删除，左上角 ✕ 关闭，📷 可以附小票照片。
- **报表**：一次看一个月，用 ‹ › 切换。显示支出、收入、结余和预算；「这个月花在哪里」可以按分类、银行卡、成员看；「分类变化」显示最近 6 个月每个分类的走势，分类多的时候点「筛选」只看想看的几个。
- **分类排序**：设置里按住分类左边的 ⋮⋮ 上下拖动，顺序会自动保存，所有成员看到的一样。
- **森林主题**：在登录页或设置里选「森林」。
- **删掉的功能**：小票文字识别（拍照附小票还在）、分账和结算。旧的分账资料留在数据库里，不会再显示，也不影响金额。

**规则也小改了一处**（允许保存「森林」主题）。请把 `firestore.rules` 再粘贴到 Firebase 控制台发布一次；不发布的话，其他功能都正常，只是换手机登录时森林主题跟不过去。



## 上一次更新（安全修复、收入、预算、固定账单）

**这次修了一个安全漏洞，请一定把新的 `firestore.rules` 粘贴到 Firebase 控制台并发布。**
步骤：[Firebase 控制台](https://console.firebase.google.com) → 项目 **my-expense-app-63a6d** → **Firestore Database** → **Rules（规则）** → 删掉旧内容 → 粘贴仓库里的 `firestore.rules` 全部内容 → **Publish（发布）**。

- **安全修复**：旧规则里，任何登录的人只要知道账本编号，就能把自己加进账本；普通成员也能删除整个账本、换掉创建者。现在：只能通过接受邀请加入；只有创建者能删除账本、移除成员；普通成员只能退出自己、改自己的昵称和头像。
- **收入**：记一笔时顶部可以选「支出 / 收入」。首页显示本月收入和结余，月报也会对比收入。旧账本第一次切到「收入」时，会自动加上 工资 / 奖金 / 其他收入 三个分类。设置里分开管理支出分类和收入分类。
- **预算**：设置 → 账本里可以填「每月总预算」；点某个支出分类可以填这个分类的预算。首页会显示进度条，快用完变黄，超支变红。
- **固定账单**：记一笔时勾选「每月重复记这一笔」，或在设置 → 固定账单里新建。到了日子打开 App 就会自动记上（错过的月份会补记，不会重复）。可以暂停、恢复、修改、删除；已经记上的账单不受影响。
- **更快**：以前每次打开都会下载账本的全部历史账单来算分账，现在只下载有分摊的那些。图表库改为不阻塞首屏。
- **修好的问题**：新注册用户第一次记账显示「没有权限」、记的账要刷新才出现；编辑旧账单时，如果它的分类或银行卡已被删除，会被悄悄改成第一个分类；月报里两个同名成员会被算成一个人；设置页在别人同步数据时会清空你正在输入的内容；删除存款记录失败没有提示；切换账本后邀请文字还是上一个账本的；月报页的月份框会撑出屏幕。


这次更新加了这些功能（手机上打开设置就能用）：

- **个人资料**：可以改昵称，上传一张照片当头像，或从自带的小头像里挑一个。照片会在手机里自动缩小，**不用开通 Firebase Storage**。同一个账本里的其他人能看到你的名字和头像。
- **货币**：每个账本可以选自己的货币（马币 MYR、人民币 CNY、美元 USD、新加坡元 SGD、欧元 EUR、墨西哥比索 MXN、巴西雷亚尔 BRL）。首页、账单和存款都会换成对应的符号。以前的账本没设过货币，仍然显示人民币 ¥。
- **语言**：设置里可以在简体中文和 English 之间切换，手机会记住。
- **分类图标**：点分类名称可以改名字，也可以从全部标准 emoji 里搜索挑选图标（按类别分组）。旧分类没有图标也没关系，会继续显示名字的第一个字。
- **三种主题**：清新、暖色、深色，在登录页或设置里点色块即可，手机会记住。

## 重要：更新程序后必须重新发布 Firestore 规则

请打开 [Firebase 控制台](https://console.firebase.google.com) → 项目 **my-expense-app-63a6d** → **Firestore Database** → **Rules（规则）**。

删掉里面的旧内容，把仓库里的 `firestore.rules` **全部**粘贴进去，点 **Publish（发布）**。

不发布的话：记账、邀请、存款都还和以前一样。昵称和头像仍会通过账本成员信息给同一个账本里的人看到。但是换一台手机登录时，头像、主题和语言可能跟不过去。

不需要开通 Storage，也不需要新建索引。

## 第一步：建立 GitHub 仓库
1. 打开 https://github.com 注册/登录。
2. 右上角 **＋ → New repository**，名字随意（如 `expense`），选 **Public**，点 **Create repository**。

## 第二步：上传文件
1. 解压 `expense-app.zip`。
2. 在仓库页面点 **Add file → Upload files**。
3. 把解压出来的**所有文件和 icons 文件夹**拖进去（注意：是文件夹里面的内容，`index.html` 要在最外层）。
4. 点底部绿色 **Commit changes**。

## 第三步：开启 GitHub Pages
1. 仓库 **Settings → Pages**。
2. Source 选 **Deploy from a branch**，Branch 选 **main**，文件夹选 **/ (root)**，点 **Save**。
3. 等 1–2 分钟，页面顶部会出现网址：`https://你的用户名.github.io/仓库名/`。

## 第四步：Firebase 控制台设置（https://console.firebase.google.com ，项目 my-expense-app-63a6d）
1. **Authentication → Sign-in method**：启用 **电子邮件/密码 (Email/Password)**。
2. **Authentication → Settings → Authorized domains（授权网域）**：点 **Add domain**，填 `你的用户名.github.io`（不要带 https 和仓库名）。
3. **Firestore Database**：如未创建，点 **创建数据库**（选离你近的区域，如 asia-southeast1，生产模式）。
4. **Firestore → Rules（规则）** 标签：删除原内容，把 `firestore.rules` 文件全部内容粘贴进去，点 **Publish（发布）**。
5. 不需要创建任何索引，也不需要开通 Storage。

## 第五步：添加到手机主屏幕
- **iPhone**：用 **Safari** 打开网址 → 点底部 **分享按钮** → **添加到主屏幕**。
- **Android**：用 **Chrome** 打开 → 右上角 **⋮ 菜单** → **添加到主屏幕 / 安装应用**。

规则文件没有变。如果你已经按上面发布过规则，**这次不用再粘贴、不用再发布**。也不用开通 Storage。

- **备注**：账单里的长备注会自动换行，不再被截断。

## 新用户建不了账本（已修好）

原因：新建账本时，程序把「账本」和「里面的分类」放在同一次保存。规则要先看到你已经是成员，才允许写分类。账本还没保存成功时，规则看不到你，于是整次保存被拒绝。新注册的人就没有任何账本。

现在会先保存账本，再保存分类。同时更新了规则，让第一次创建更稳妥，邀请也按小写邮箱匹配。

**请把新的 `firestore.rules` 再粘贴到 Firebase 控制台并发布。** 不发布的话，先保存账本这一步用现有规则也能成功；发布后更稳。

## 邀请和月报

- 设置里输入对方邮箱即可邀请，待接受的邮箱会列出来。可以复制或发送一段话，里面有网址 https://kenny193.github.io/expense-app/ ，并写明要用这个邮箱注册。
- 对方登录后，顶部会出现「接受 / 忽略」。没有账本时也可以点「创建我的账本」。
- 底部「月报」可以选两个月对比总额、分类、账户、成员（涨跌百分比），并看最近 6 个月。

## 再往后的功能

- **删除账本**：只有创建者能删。要输入账本名字确认。分类、账户、账单、小票和存款会一起删掉。删完会切到别的账本；如果没有了，会新建一个个人账本。其他成员看到的是「退出此账本」。这次**没有改** Firestore 规则，不用再发布。
- **表情**：选图标时先看到「全部」，也可以按类别看，搜索会在所有表情里找。手机上格子对齐，在弹窗里滚动，不会把页面撑出屏幕。
- **分账**：记一笔时可以按平分、金额或百分比分给成员，并记下谁先付钱。首页「分账」会显示谁该给谁，也可以记一笔结算。没有分摊的旧账单还是算付款人自己的。按成员看图表时，用的是每个人分到的那一份。
- **金额输入**：记账、分摊金额、存款的存入/取出/目标，都只要按数字。小数点会自动出现，比如依次按 1、8、8、7、7 就是 188.77。退格删掉最后一位。手机上是数字键盘。

## 使用说明
- 注册后自动生成「个人账本」。顶部点账本名称可切换或新建（情侣账本、旅行账本…）。
- 登录页可以先选语言和主题。设置页里也可以改，并且会跟着账号走（需要已经发布上面的规则）。
- 设置页顶部可以改昵称和头像。上传的照片只会存成很小的图片。
- 设置页可以改账本货币、改名、编辑分类（名字和图标）、增删分类和银行卡、按邮箱邀请成员。对方用该邮箱注册/登录后顶部会出现邀请，点「接受」即可。
- 首页图表可以按分类、银行卡或成员看。分类图标会出现在图例和每一笔账单上。账单列表可以筛选。长备注会整段显示。
- 离线也能记账，联网后自动同步。

## 更新程序
修改文件后重新 Upload 覆盖即可。当前缓存版本是 `sw.js` 第一行的 `expense-v9`。如果手机上看不到更新，把它改成 `expense-v10` 再上传。

这次更新改了 `firestore.rules`，**请再粘贴到 Firebase 控制台并发布**。不发布时，新用户仍可以先建账本（程序已改成先保存账本）；发布后，第一次创建和接受邀请更稳妥。

## 以后想做成真正的 App（Capacitor）
可以用 Capacitor 把这个网页打包成 iOS/Android 安装包：需要电脑安装 Node.js，`npm i @capacitor/core @capacitor/cli`、`npx cap init`、把这些文件放到 `www` 目录、`npx cap add android / ios`，再用 Android Studio / Xcode 打包。届时需把 `localhost` 等域名加到 Firebase 授权网域。这一步需要一定技术基础，可以以后再做。
